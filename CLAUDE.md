# AI Engineering Framework

Framework: `.agent-skill/` when mounted as a submodule, or this repository root when
working on the framework itself. Preserve project-specific rules below this reference.

For non-trivial tasks, read `router/ROUTER.md` at the framework root. Classify intent,
inspect minimal repository evidence, determine relevant domains and complexity,
resolve the minimum workflow and non-overlapping skill set, then load required bodies
and resources. Prefer current project evidence and constraints over generic advice.
Verify before claiming completion; use proportional local verification for trivial edits.

Never load all available skills or two owners of the same responsibility.
Do not ask the user to choose a skill when intent can be inferred.
