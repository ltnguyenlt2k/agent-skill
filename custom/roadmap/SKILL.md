# Roadmap

Inspect the requested horizon, goals, current project state and constraints. Separate
known facts from assumptions. Research material gaps through the available research
owner before committing to a sequence; do not invent reliable-looking dates.

Produce the relevant objective, current state, assumptions, phases, milestones,
dependencies, risks, validation gates and deliverables. Show Now / Next / Later and
estimated sequencing when useful. Link milestones to observable outcomes. State
uncertainty and tradeoffs; estimates are conditional on resources and dependencies.

Match detail to the requested horizon. Ask only for missing information that materially
changes priorities. Deliver a roadmap document in the project's established location.
Check that milestones support the objective, dependencies are coherent, and each gate
has measurable evidence. This skill does not execute implementation or change code.
