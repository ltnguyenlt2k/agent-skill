# Complexity

| Level | Evidence | Max primary skills active in a phase |
| --- | --- | --- |
| trivial | Mechanical, local, clear verification | 1 |
| small | One component, known behavior, few dependencies | 2 |
| medium | Several components or uncertain integration | 3 |
| complex | Cross-system design/integration, substantial unknowns | 5 |

Estimate from change scope, uncertainty, dependencies and validation cost, not word
count. A feature is not automatically complex. These limits constrain simultaneous
context in each phase, not the union of sequential responsibilities across a task.
If a phase exceeds its budget, remove optional work or sequence independent owners
and validate each active selection. Do not inflate complexity just to load more skills.
