# Responsibility and conflicts

Enabled means available for routing, not always active. Filter by task, relevant
domain and condition before loading. Reject duplicate responsibilities and either
side of a declared conflict. Disabled entries remain inactive unless an explicit
owner switch selects them; remove the default owner before enabling its alternative.

Superpowers alone owns general engineering workflows. Matt Pocock contributes
research only. UI UX Pro Max owns design intelligence by default; React implementation
quality and final web accessibility audit are separate responsibilities. Security
is conditional on authentication/authorization, secrets, uploads, untrusted queries,
network-facing APIs, paths or cryptography being in the affected scope.

Upstream instructions to load siblings, global orchestrators or spawn agents must
pass this router and host authorization. Never install upstream plugins/hooks
implicitly. security-guidance is a plugin package, not a SKILL.md: read its README
and inspect relevant hook rules/prompts without running API-backed hooks by default.
For Matt Pocock research, use its primary-source/report guidance in the current agent
when delegation is unavailable or unjustified; do not manufacture a parallel task.
